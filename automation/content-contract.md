# Контракт контента для автосбора

Пайплайн n8n должен создавать файл `src/content/articles/<slug>.md` строго в этом формате.
Поля обязаны соответствовать схеме `src/content.config.ts`.

## Имя файла

`news-<латинский-слаг>.md` — только латиница, цифры и дефисы. Пример: `news-avidbots-neo3-aeroport.md`.
Слаг должен быть детерминирован (например, из нормализованного заголовка) — это часть защиты от дублей.

## Frontmatter (обязательно)

```markdown
---
title: "Заголовок на русском (перевод/рерайт, без копирования оригинала)"
description: "1–2 предложения-аннотация на русском."
pubDate: 2026-07-28            # ГГГГ-ММ-ДД, дата публикации новости у нас
category: "Технологии"         # ОБЯЗАТЕЛЬНО одно из: Офисы | Склады | Бизнес-центры | Технологии
rubric: "Новости"              # для автоновостей всегда "Новости"
tags: ["вендор", "тип-объекта", "тема"]
objectTypes: ["склад"]         # из: склад | ТЦ | БЦ | аэропорт | вокзал | логистика
vendors: ["Avidbots"]          # упомянутые производители/бренды
robotType: ["поломоечный"]     # поломоечный | подметальный | дезинфектор | мойщик окон | ...
readingTime: 2
animation: "robot-roll"        # один из ключей (см. ниже)
origin: "auto"                 # ВСЕГДА "auto" для автосбора
source:
  name: "Имя источника"
  url: "https://оригинал/новости"   # ссылка на первоисточник (обязательно)
  publishedAt: 2026-07-27           # дата оригинала
---

Тело статьи на русском: 2–4 абзаца оригинального рерайта.
НЕ копировать текст источника дословно. Допустима 1 короткая цитата (<15 слов) в кавычках.
Факты — из источника; ссылка на оригинал уже в поле source.
```

## Ключи анимаций (`animation`)

Подбирать по теме. Допустимые значения:

| ключ | когда использовать |
| --- | --- |
| `robot-roll` | общие новости, кейсы, внедрения, склад |
| `roi-chart` | экономика, окупаемость, инвестиции, цены |
| `route-map` | навигация, технологии, маршруты, обслуживание |
| `humans-robots` | рынок, партнёрства, кадры, «люди+роботы» |
| `scan-pulse` | обзоры моделей, дезинфекция, мойка окон/фасадов |

## Требования к тексту (правовые)

- Только рерайт и краткая суммаризация, без копирования абзацев источника.
- Обязательная атрибуция: заполнено `source.name` и `source.url`.
- Уважать robots.txt/условия источников; предпочитать официальные RSS и открытые API.
- Публиковать только релевантное робо-клинингу / автоматизации уборки коммерческих объектов
  (фильтр по ключевым словам из `sources.json`).
