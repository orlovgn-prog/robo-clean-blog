# Автосбор новостей — пакет n8n (Claude API)

Конвейер: **RSS → фильтр релевантности → дедуп → Claude (перевод + рерайт + классификация) →
сборка Markdown → коммит `.md` в GitHub → авто-деплой**. По расписанию **пн/ср/пт 09:00**.

Файлы:
- `n8n-workflow.json` — импортируемый воркфлоу n8n.
- `sources.json` — список RSS-лент и ключевых слов (конфиг).
- `content-contract.md` — формат `.md`, который производит пайплайн (совпадает со схемой сайта).

> Решения проекта: пайплайн — **n8n**, LLM — **Claude API**, публикация — **автопубликация**.

## Что должен подключить владелец (один раз)

Автономность «без рук» требует трёх внешних вещей — их подключаете вы:

1. **GitHub-репозиторий** с этим проектом (сейчас проект локальный — нужно `git init` и залить на GitHub).
2. **Деплой** на Vercel или Netlify: команда сборки `npm run build`, каталог `dist`.
   Каждый коммит в `main` → автоматическая пересборка и публикация.
3. **n8n** (облако n8n.cloud или self-hosted) + **ключ Anthropic (Claude)**.

## Пошаговая настройка

1. **Залить проект на GitHub**
   ```bash
   cd ~/robo-clean-blog
   git init && git add -A && git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/<логин>/robo-clean-blog.git
   git push -u origin main
   ```

2. **Деплой** (Vercel): New Project → импорт репозитория → framework Astro определится сам →
   Build `npm run build`, Output `dist`. Пропишите свой домен в `astro.config.mjs` (`site`).

3. **Импортировать воркфлоу**: в n8n → Workflows → Import from File → `n8n-workflow.json`.

4. **Создать креденшелы в n8n**
   - **Anthropic** (нода «Claude»): тип *Header Auth* → header `x-api-key` = ваш ключ Anthropic.
   - **GitHub** (нода «GitHub: коммит .md»): *GitHub API* с personal access token (scope `repo`).

5. **Донастроить ноды**
   - «Ленты (из sources.json)»: вставьте актуальный список из `sources.json`.
   - «Claude…»: модель `claude-sonnet-5` — при необходимости замените на доступную вам модель Claude.
   - «GitHub…»: укажите `owner` (ваш логин) и `repository` (`robo-clean-blog`), ветка `main`.

6. **Проверить вручную**: кнопка *Execute Workflow* — пайплайн создаст 1–N файлов
   `src/content/articles/news-*.md` в репозитории. Деплой подхватит их автоматически.

7. **Активировать**: тумблер *Active* → расписание пн/ср/пт заработает само.

## Как это устроено

- **Дедупликация**: внутри запуска + между запусками через `workflow static data`
  (хранит нормализованные заголовки). Для долговременной защиты от дублей вынесите список
  «seen» в БД или в коммитимый файл (при переимпорте воркфлоу static data сбрасывается).
- **Релевантность**: нода «Фильтр» отсекает всё, где нет ключевых слов из списка; плюс
  сам Claude возвращает `{skip:true}`, если новость не про робо-клининг.
- **Анимация**: Claude выбирает ключ из библиотеки (`robot-roll`/`roi-chart`/…), сайт
  подставляет соответствующий анимированный шаблон.
- **Правовое**: только рерайт + краткая суммаризация, обязательная ссылка на первоисточник
  в поле `source`. Уважайте robots.txt/условия источников, предпочитайте официальные RSS.

## Модерация вместо автопубликации (если передумаете)

Сейчас новости публикуются сразу. Чтобы включить очередь ревью, в ноде «Собрать Markdown»
добавьте в frontmatter строку `draft: true` — материалы перестанут показываться на сайте,
пока вы вручную не уберёте `draft` в конкретном файле.
