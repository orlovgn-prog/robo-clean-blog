# RoboClean — блог о роботах для уборки

Блог о робототехнике для уборки офисов, складов и бизнес-центров.
Собран на [Astro](https://astro.build). Статьи — это простые Markdown-файлы,
поэтому вести блог можно без знания программирования.

## Запуск на своём компьютере

> Node.js уже установлен в `~/.local/node` и прописан в PATH.
> В новом терминале команды `npm` работают сразу.

```bash
cd ~/robo-clean-blog
npm run dev       # локальный просмотр на http://localhost:4321
```

Другие команды:

```bash
npm run build     # собрать статический сайт в папку dist/
npm run preview   # посмотреть собранный сайт
```

## Как добавить новую статью

1. Зайдите в папку `src/content/articles/`.
2. Скопируйте `_ШАБЛОН.md.txt` как образец.
3. Создайте новый файл с расширением **`.md`**, например
   `moya-novaya-statya.md`. Имя файла (латиницей) станет адресом статьи.
4. Заполните «шапку» (frontmatter) между `---` и напишите текст в Markdown.
5. Сохраните файл — статья автоматически появится на сайте и в нужной категории.

Минимальная «шапка» статьи:

```markdown
---
title: "Заголовок статьи"
description: "Короткое описание для списков и поиска."
pubDate: 2026-07-03
category: "Офисы"     # Офисы | Склады | Бизнес-центры | Технологии
tags: ["тег1", "тег2"]
---

Текст статьи в формате Markdown...
```

Чтобы скрыть статью (черновик), добавьте в шапку `draft: true`.

## Структура проекта

```
src/
├─ content/articles/     ← СТАТЬИ (правьте здесь)
├─ pages/                ← страницы сайта
│  ├─ index.astro        ← главная
│  ├─ about.astro        ← «О блоге»
│  └─ articles/          ← список и страница статьи
├─ components/           ← шапка, подвал, карточка, робот
├─ layouts/              ← общий каркас страниц
└─ styles/global.css     ← цвета и общий дизайн
```

## Дизайн

Цвета и оформление задаются переменными в начале `src/styles/global.css`
(блок `:root`). Поменяв там значения, вы измените палитру всего сайта.

## Публикация в интернете

Сайт статический, его можно бесплатно разместить на Vercel, Netlify или
Cloudflare Pages: подключите папку проекта, команда сборки — `npm run build`,
каталог с результатом — `dist`. Перед публикацией укажите свой домен в
`astro.config.mjs` (поле `site`).

## Автоматическая генерация статей через ИИ (на будущее)

Так как статья — это обычный `.md` файл, наполнение легко автоматизировать:
скрипт может обращаться к Claude API, получать текст по заданной теме и
сохранять готовый файл в `src/content/articles/`. Если понадобится такой
пайплайн — его можно добавить отдельно.
